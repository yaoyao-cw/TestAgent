# TestAgent 系统架构文档

## 概述

TestAgent是一个基于AI的智能测试代理系统，采用多智能体协作架构，通过大型语言模型（LLM）驱动的智能体协同工作，实现从需求分析到测试报告生成的全流程自动化测试解决方案。

## 核心组件

### 1. 多智能体系统

#### 1.1 协调器 (Coordinator)
- **职责**: 任务分发和意图识别
- **输入**: 用户请求和系统配置
- **输出**: 任务目录和初始化信息
- **工作流程**: load → llm → router

#### 1.2 规划器 (Planner)
- **职责**: 测试计划生成和优化
- **技术**: 思维链(CoT)和树状思维(ToT)
- **输出**: plan.md文件包含推理过程
- **特性**: 任务分解和优先级排序

#### 1.3 测试团队路由器 (TestTeam)
- **职责**: 根据任务状态路由到相应智能体
- **输入**: 计划和todo.md状态
- **路由目标**: Tester或Coder
- **决策依据**: 当前任务进度和类型

#### 1.4 测试员 (Tester)
- **职责**: 测试用例设计和思维导图生成
- **技术**: ReAct循环（推理-行动-观察）
- **输出**: 测试用例和思维导图
- **特性**: 内部多步推理和工具调用

#### 1.5 编码员 (Coder)
- **职责**: 测试脚本编写和代码生成
- **技术**: ReAct循环生成测试脚本
- **输出**: 可执行的测试代码
- **集成**: E2B Sandbox执行环境

#### 1.6 评审员 (Reviewer)
- **职责**: 质量评估和改进建议
- **评审内容**: 代码质量、测试覆盖度、错误分析
- **输出**: 反馈报告和修复策略
- **决策**: 通过/不通过判断

### 2. 任务监控系统

#### 2.1 任务创建状态监控
- **TaskCreationMonitor**: 监控任务创建的完整生命周期
- **ProgressTracker**: 提供实时进度更新和状态反馈
- **TaskStatusNotifier**: 向用户推送任务状态变化通知

### 3. 智能错误处理系统

#### 3.1 错误消息格式化器
- **ErrorMessageFormatter**: 将技术错误转换为用户友好的消息格式
- **FormattedMessage**: 结构化的错误消息数据模型
- **MessageStyle**: 支持多种消息样式（简洁、详细、技术、友好）

#### 3.2 错误处理流程
```
技术错误 → 错误识别 → 消息格式化 → 解决方案生成 → 用户界面展示
```

#### 3.3 支持的错误类型
- **网络错误**: 连接超时、DNS解析失败、连接拒绝等
- **API错误**: HTTP状态码错误、认证失败、权限不足等
- **系统错误**: 配置错误、资源不足、服务不可用等
- **通用错误**: 其他未分类的错误类型

#### 3.4 错误恢复机制
- **自动重试**: 支持指数退避的智能重试策略
- **降级处理**: 在服务不可用时提供降级功能
- **用户引导**: 提供具体的解决方案和操作建议
- **错误追踪**: 生成唯一错误ID便于问题追踪

#### 2.2 任务创建流程
```
初始化 → 服务验证 → 输入验证 → 资源分配 → 任务生成 → 持久化 → 通知
 10%      20%       10%       20%       30%       8%      2%
```

#### 2.3 状态管理
- **TaskCreationStatus**: pending, validating, creating, completed, failed, cancelled, paused
- **TaskCreationStep**: initialization, service_validation, input_validation, resource_allocation, task_generation, persistence, notification
- **实时通知**: WebSocket推送状态变化和进度更新

### 4. 统一工作空间设计

#### 3.1 文件命名规范
```
tasks/{task_id}/
├── 00_Coordinator_Init_v1.md          # 协调器初始化
├── 01_Planner_Plan_v1.md              # 规划器计划
├── 02_Tester_Mindmap_v1.json          # 测试员思维导图
├── 03_Tester_TestCases_v2.md          # 测试用例（版本2）
├── 04_Coder_Scripts_v1.py             # 编码员脚本
├── 05_Executor_Results_v1.json        # 执行结果
├── 06_Reviewer_Report_v1.md           # 评审报告
├── todo.md                            # 动态任务状态
└── _error.log                         # 错误记录
```

#### 3.2 状态管理
- **全局状态**: 任务ID、当前步骤、活跃智能体
- **文件引用**: 智能体间通过文件路径交互
- **版本控制**: 支持文件版本迭代和回滚
- **任务恢复**: 基于文件状态自动恢复执行
- **创建监控**: 任务创建过程的详细状态跟踪

## 技术架构

### 1. 后端技术栈
- **Python 3.11+**: 主要编程语言
- **FastAPI**: Web框架，提供REST API和WebSocket支持
- **LangChain/LangGraph**: AI代理框架和工作流编排
- **ChromaDB**: 向量数据库，用于RAG知识库
- **Redis**: 缓存和会话存储
- **Pydantic**: 数据验证和序列化

### 2. 前端技术栈
- **React 18**: 前端框架
- **TypeScript**: 类型安全的JavaScript
- **Vite**: 构建工具
- **Tailwind CSS**: 样式框架
- **React Query**: 数据获取和状态管理
- **Socket.io**: 实时通信

### 3. AI/ML集成
- **LiteLLM**: 多LLM提供商统一接口
- **OpenAI, Anthropic, Google**: LLM提供商
- **Sentence Transformers**: 文本嵌入
- **MCP (Model Context Protocol)**: 外部工具集成

### 4. 部署和基础设施
- **Docker & Docker Compose**: 容器化部署
- **Nginx**: 反向代理
- **Prometheus + Grafana**: 监控和可视化
- **Uvicorn**: ASGI服务器

## 数据流架构

### 1. 请求处理流程
```
用户请求 → FastAPI → 协调器 → 规划器 → 测试团队 → 测试员/编码员 → 评审员 → 报告生成
```

### 2. 数据存储模式
- **任务数据**: 文件系统存储，支持版本控制
- **缓存数据**: Redis存储，提升响应速度
- **向量数据**: ChromaDB存储，支持语义搜索
- **监控数据**: Prometheus存储，Grafana可视化

### 3. 实时通信
- **WebSocket连接**: 实时任务进度更新
- **事件驱动**: 智能体状态变化通知
- **日志流**: 实时执行日志推送

## 安全架构

### 1. 代码执行安全
- **E2B Sandbox**: 强隔离执行环境
- **资源限制**: CPU、内存、时间限制
- **恶意代码检测**: 静态分析和动态监控

### 2. 数据安全
- **敏感信息脱敏**: PII数据处理
- **访问权限控制**: 基于角色的权限管理
- **数据加密**: 传输和存储加密

### 3. API安全
- **JWT身份认证**: 无状态认证机制
- **请求频率限制**: 防止滥用和攻击
- **输入验证**: 严格的参数验证和过滤

## 性能优化

### 1. 缓存策略
- **多层缓存**: 内存缓存 + Redis缓存
- **LLM响应缓存**: 减少重复推理成本
- **RAG检索缓存**: 提升知识库查询速度

### 2. 并发处理
- **异步执行**: FastAPI异步框架
- **任务队列**: 后台任务处理
- **资源池**: 连接池和线程池管理

### 3. 监控和优化
- **性能指标**: 响应时间、吞吐量、错误率
- **资源监控**: CPU、内存、磁盘使用率
- **智能体行为分析**: 执行效率和质量评估

## 总结

TestAgent系统架构采用现代化的微服务设计理念，通过多智能体协作、文件系统统一工作空间、工具状态机管理等创新设计，实现了高度智能化、可扩展、可维护的测试平台。系统在保证功能完整性的同时，充分考虑了性能优化、安全性和可扩展性，为企业级测试自动化提供了完整的解决方案。
