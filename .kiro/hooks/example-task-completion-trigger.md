# 任务完成自动化触发示例

## 概述
本文档展示如何在任务完成时自动触发git工作流程，并确保遵循语言规范。

## 使用方式

### 1. 手动触发（推荐）
当完成一个任务时，可以手动触发集成任务管理器：

```
请执行任务完成后的自动化流程
```

### 2. 任务状态变更触发
当任务状态从"进行中"变更为"已完成"时，系统会自动触发相关hooks。

### 3. 代码文件变更触发
当检测到代码文件变更时，会自动提示执行git工作流程。

## 自动化流程

### 阶段1: 语言规范检查
- 确保所有交互使用中文
- 检查代码注释是否使用中文
- 验证文档是否使用中文编写

### 阶段2: Git工作流程执行
1. **检查git状态**
   ```bash
   git status
   ```

2. **代码格式化**
   ```bash
   python -m black src/ tests/
   ```

3. **添加变更**
   ```bash
   git add .
   ```

4. **创建提交**（使用中文）
   ```bash
   git commit -m "feat(功能模块): 实现具体功能的中文描述"
   ```

5. **推送到远程**
   ```bash
   git push origin feature/分支名称
   ```

### 阶段3: 任务完成确认
- 更新任务状态为已完成
- 生成任务完成报告
- 提供后续操作建议

## 语言规范要求

根据 `.kiro/steering/language.md` 的规定：

### 必须使用中文的场景
- 用户交互对话
- 提交信息描述
- 代码注释
- 错误信息
- 文档编写

### 可以使用英文的场景
- 变量名、函数名、类名
- 第三方库和框架术语（但需要中文解释）

## 示例对话

### 任务完成触发
```
用户: 我已经完成了智能体功能的开发
助手: ✅ 任务完成！现在自动执行Git工作流程...

🔍 检查当前git状态...
🐍 运行代码格式化...
📝 创建规范化提交...
🚀 推送到远程仓库...

任务已成功完成并提交到代码仓库！
```

### 语言规范提醒
```
助手: 🌐 语言规范提醒：
- 请确保所有代码注释使用中文
- 提交信息将使用中文描述
- 如有技术术语，会提供中英文对照
```

## 配置文件说明

### 相关Hooks
- `task-completion-git-workflow.kiro.hook` - 任务完成时的git工作流
- `task-status-monitor.kiro.hook` - 任务状态监控
- `language-compliance-check.kiro.hook` - 语言规范检查
- `integrated-task-manager.kiro.hook` - 集成任务管理器
- `git-feature-workflow.kiro.hook` - Git功能分支工作流（已更新）

### Steering规则
- `.kiro/steering/language.md` - 语言规范设置

## 最佳实践

1. **任务开始前** - 确认语言规范要求
2. **任务执行中** - 使用中文编写注释和文档
3. **任务完成后** - 自动触发git工作流程
4. **代码提交时** - 使用中文编写提交信息
5. **推送完成后** - 确认任务状态更新

这样可以确保每个任务都按照统一的标准完成，并且严格遵循项目的语言规范。
